## 📖 项目简介

本仓库提供了系统化的 Git 学习资料，适合不同水平的开发者学习和参考。内容涵盖 Git 基础概念、常用命令、工作流程和实战案例。

### 特点

- ✨ **系统化学习路径** - 从基础到高级，循序渐进
- 📝 **详细的命令说明** - 包含语法、参数和实际示例
- 🎯 **实战案例丰富** - 真实场景的应用示例
- 🔧 **工作流程指导** - 团队协作最佳实践
- 📋 **速查表** - 快速查找常用命令

1. 完成 [`04-实战案例.md`](./04-实战案例.md) 中的所有场景
2. 在实际项目中应用所学知识

## 💡 快速开始

### 安装 Git

```bash
# macOS
brew install git

# Ubuntu/Debian
sudo apt-get install git

# Windows
# 下载安装器：https://git-scm.com/downloads
```

### 配置 Git

```bash
# 设置用户名
git config --global user.name "Your Name"

# 设置邮箱
git config --global user.email "your.email@example.com"

# 查看配置
git config --list
```

### 克隆本仓库

```bash
git clone https://github.com/beautyhubcode/gitLearn.git
cd gitLearn
```

## 🛠️ 贡献指南

欢迎提交 Issue 和 Pull Request！

### 如何贡献

1. Fork 本仓库
2. 创建你的特性分支 (`git checkout -b feature/AmazingFeature`)
3. 提交你的修改 (`git commit -m 'Add some AmazingFeature'`)
4. 推送到分支 (`git push origin feature/AmazingFeature`)
5. 开启一个 Pull Request

### 贡献类型

- 📝 修正错别字或内容错误
- ✨ 添加新的内容或示例
- 🐛 修复 Bug
- 💡 提出改进建议
- 📖 完善文档
